# พรหมญาณออนไลน์ — หมอวิทยา ธรรมนาย

ระบบเปิดไพ่พรหมญาณ พัฒนาแยกจาก `Wittaya-Tasu/WITTAYA_PMY` เพื่อทยอยปรับประสบการณ์ใช้งาน โดยเริ่มจากความเข้าใจง่ายในการใช้งาน

## ระยะที่ 1: ขั้นตอนชัดเจน

- แสดงขั้นตอน เตรียมตัว → ระบุข้อมูล → เลือกและยืนยัน → ดูผล
- แจ้งการใช้สิทธิ์ 12 ใบตรงจุดยืนยันและเมื่อบันทึกผลสำเร็จ
- ข้อมูลแบบ 12 ใบไม่บังคับ ส่วนแบบ 3 ใบต้องระบุคำถามก่อนเลือก
- แสดงจำนวนไพ่ที่เลือกและตำแหน่งถัดไป ยกเลิกไพ่เพื่อเปลี่ยนการเลือกได้
- เพิ่มปุ่มยืนยันก่อนเปิดผล ไม่มีการเปิดหรือบันทึกอัตโนมัติเมื่อเลือกครบ
- แสดงสถานะกำลังบันทึก สำเร็จ หรือยังยืนยันไม่ได้ตามคำตอบจริงจากระบบ
- รักษาไพ่ 67 ใบ ผัง 12 ตำแหน่ง กฎไพ่พิเศษ สี และความสัมพันธ์ตามวัน
- เพิ่มขนาดไพ่และระยะห่างบนจอเล็ก ผังผล 12 ใบเลื่อนแนวนอนได้

## ปรับตามผลทดสอบผู้ใช้

- ย่อหน้าแรกให้เหลือจรรยาบรรณที่ขยายเต็มพื้นที่และปุ่มเริ่ม
- จัดบทอธิษฐานเป็นวลีที่ไม่ตัดคำกลางวลี พร้อมปรับขนาดตามหน้าจอ
- เลือกหัวข้อคำถามได้ 12 หมวด เลือกหลายหมวดและเพิ่มข้อความเองได้ หัวข้อรวมอยู่ในข้อความคัดลอกและข้อมูลที่ส่งบันทึก
- ตัดหัวข้อซ้ำในกล่องเลือกไพ่และขยายคำแนะนำ
- ตัวเลขไพ่ที่เลือกใหญ่ขึ้นสองเท่า ไพ่ใบล่าสุดใหญ่กว่าและใช้พื้นทองกับตัวเลขเข้ม
- แยกชื่อเดือนเป็นบรรทัดใหม่ใต้ชื่อผังผล 12 ใบ
- แก้สีปุ่มเครื่องมือด้านซ้าย พร้อมสัญลักษณ์และจุดสีประจำวัน
- รายชื่อไพ่ใช้ Sarabun และลดระยะห่างทั้งแบบ 12 ใบและ 3 ใบ
- ช่องพิมพ์คำถาม 3 ใบใช้ตัวอักษรใหญ่ขึ้นสองเท่า
- จัดกลุ่มจรรยาบรรณไว้กึ่งกลางโดยเลขข้ออยู่แนวเดียวกัน รวมข้อความความลับเป็นประโยคเดียวและเน้นข้อความสำคัญด้วยสี
- ภาพผลไพ่ไม่แสดงกล่องคำถามเพิ่มเติม ส่วนสถานการณ์ที่กรอกยังแสดงได้
- หน้าเข้าสู่ระบบแสดงชื่อหมอวิทยา ธรรมนาย และแบบฟอร์มเข้าสู่ระบบ

## การใช้งานแอดมิน

แอดมินเข้าสู่ระบบครั้งเดียวแล้วสลับเมนู “จัดการรหัส” กับ “เปิดไพ่ / ทดสอบระบบ” ได้ โดยชุดไพ่และข้อมูลที่กำลังใช้งานยังคงอยู่เมื่อสลับหน้า

หน้าเปิดไพ่ของแอดมินเริ่มชุด 12 ใบใหม่ หรือเริ่มคำถาม 3 ใบโดยตรงได้ ใช้การเลือกไพ่ สุ่มไพ่ ไพ่พิเศษ ตัวกรอง ความสัมพันธ์ตามวัน คัดลอกผล และบันทึกภาพร่วมกับระบบปกติ

ค่าเริ่มต้นเป็นการแสดงผลทดสอบโดยไม่เรียกบันทึกลงชีต หากเปิด “บันทึกผลที่ยืนยันลงชีต” จะบันทึกประเภท `ทดสอบแอดมิน 12 ใบ` หรือ `ทดสอบแอดมิน 3 ใบ` ใน Results โดยไม่เข้ากฎตัดสิทธิ์ของ Apps Script เดิมที่ทำงานเฉพาะประเภท `12 ใบ` ไม่จำเป็นต้องสร้างรหัสเจ้าชะตาสำหรับแอดมิน

## ความสวยงามและความสม่ำเสมอ

ใช้ชุดสีเขียวเข้ม–ทองหม่น–พื้นงาช้างร่วมกันทั้งหน้าเข้าสู่ระบบ ขั้นตอนเปิดไพ่ ผลลัพธ์ และหน้าแอดมิน ใช้ Sarabun และขนาดข้อความที่เป็นระบบ พร้อมปุ่มหลัก ปุ่มรอง ปุ่มข้อความ ระยะห่าง และมุมโค้งชุดเดียวกัน

`theme.css` รวมรูปแบบหน้าจอทั้งหมด ส่วน `styles.css` เก็บสีที่มีความหมายในการอ่านไพ่จากระบบเดิม ไอคอนเป็น SVG ที่ฝังอยู่ในหน้าและในผลลัพธ์ จึงไม่ต้องเรียกไลบรารีไอคอนจากภายนอก

คงข้อความจรรยาบรรณกึ่งกลาง เลขลำดับไพ่ขนาดใหญ่ ไพ่ใบล่าสุดสีทอง บทอธิษฐานที่แบ่งตามวลี และการแยกชื่อเดือนขึ้นบรรทัดใหม่ตามผลทดสอบก่อนหน้า เครื่องมืออ่านความสัมพันธ์รองรับปุ่มคีย์บอร์ดด้วย

## การเชื่อมต่อข้อมูล

`app.js` ใช้ Google Apps Script endpoint เดิม และรูปแบบข้อมูลเดิมในแท็บ `Tokens` / `Results` ไม่มีการเปลี่ยนโครงสร้างชีตหรือเผยแพร่โค้ด Apps Script ที่มีรหัสผ่านผู้ดูแล

การใช้งานเว็บใหม่นี้ด้วยรหัสจริงจะบันทึกผลและใช้สิทธิ์ในชีตเดิม จึงควรใช้รหัสทดสอบเฉพาะเมื่อตรวจการเชื่อมต่อจริง

## ไฟล์

- `index.html` หน้าเข้าสู่ระบบและเปิดไพ่
- `select_n_show.html` หน้าเดียวกันสำหรับเส้นทางที่คุ้นเคย
- `app.js` ขั้นตอนเลือกไพ่ การแสดงผล และการเรียก API
- `theme.css` ชุดสี ตัวอักษร ปุ่ม และรูปแบบหน้าจอร่วมกันทั้งระบบ
- `styles.css` สีหมวดไพ่ที่มีความหมายตามระบบเดิม และการเรียกใช้ธีม
- `images/`, `images_small/` ภาพไพ่จากต้นฉบับ

## ตรวจสอบในเครื่อง

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```sh
npm test
npm run preview:qa
```

เปิด `http://127.0.0.1:4173` ใช้ชื่อ `qa-user` กับรหัสทดสอบใดก็ได้สำหรับเจ้าชะตา หรือ `qa-fail` เพื่อดูกรณีบันทึกไม่สำเร็จ โหมด QA ใช้ข้อมูลจำลองในเครื่องและไม่ติดต่อ Google Sheets

`npm start` เปิดเว็บโดยใช้ endpoint จริง ควรใช้เมื่อพร้อมตรวจการเชื่อมต่อจริงเท่านั้น

## ขอบเขตที่ยังไม่เปลี่ยนในระยะนี้

การตรวจสิทธิ์ฝั่ง Apps Script การป้องกันรายการซ้ำที่เซิร์ฟเวอร์ และการดูผลย้อนหลัง ยังต้องพัฒนาในระยะถัดไป การแจ้งว่าบันทึกไม่สำเร็จจึงไม่ส่งซ้ำอัตโนมัติ เพื่อป้องกันการสร้างรายการซ้ำเมื่อเครือข่ายขาดช่วง

ภาพไพ่และชื่อแบรนด์ใช้ตามต้นฉบับของเจ้าของระบบ ไม่ได้เพิ่มใบอนุญาตเผยแพร่ต่อ
