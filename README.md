# พรหมญาณส่วนตัว — หมอวิทยา ธรรมนาย

ระบบเปิดไพ่สำหรับเจ้าของบัญชีคนเดียว พัฒนาใน Repository นี้แยกจาก `Wittaya-Tasu/WITTAYA_PMY`

เว็บไซต์: https://wittaya-tasu.github.io/phrommayan-online/

## การใช้งาน

- เข้าสู่ระบบแล้วเลือกเปิดไพ่ 12 ใบ หรือเริ่มคำถาม 3 ใบได้โดยตรง
- เปิดไพ่ชุดใหม่ได้ต่อเนื่อง ไม่มีการสร้างรหัสให้ผู้อื่นหรือตัดสิทธิ์การใช้งาน
- กำหนดชื่อผู้ใช้และเปลี่ยนรหัสผ่านได้ที่เมนู “บัญชี” โดยยืนยันรหัสผ่านปัจจุบัน รหัสใหม่ยาว 12–128 ตัวอักษร
- คงไพ่ 67 ใบ กฎไพ่พิเศษ ผัง 12 ตำแหน่ง สีหมวดไพ่ และความสัมพันธ์ตามวัน
- เลือกไพ่เองหรือสุ่ม ยืนยันก่อนเปิดผล คัดลอกข้อความ และสร้างภาพผลไพ่ได้
- รายชื่อไพ่พับไว้ทุกครั้งที่เปิดผล กด “รายชื่อไพ่” เพื่อแสดง
- หน้าจอออกแบบสำหรับคอมพิวเตอร์และ iPad 13 นิ้วทั้งแนวตั้งและแนวนอน
- บทอธิษฐานเปิดได้จากเมนู โดยไม่บังคับแสดงก่อนทุกชุด

## บัญชีและข้อมูล

`backend/Code.gs` เป็น Google Apps Script สำหรับบัญชีเดียว ไม่ใช้ตาราง Tokens ในการตรวจสิทธิ์หรือบันทึกผล และปฏิเสธคำสั่ง `generate` / `list` เดิม

บัญชีเจ้าของย้ายจากค่าผู้ดูแลเดิมที่เก็บไว้เฉพาะในโปรเจ็กต์ Apps Script ครั้งเดียว หลังจากนั้นใช้ Script Properties เป็นข้อมูลบัญชี เก็บตัวตรวจรหัสผ่านแบบ HMAC-SHA256 ที่ใช้ salt และ pepper ฝั่งเซิร์ฟเวอร์ ไม่เก็บรหัสผ่านใหม่เป็นข้อความในชีตหรือ Repository โดยต้องรักษา pepper เป็นความลับด้วย วิธีนี้ไม่ใช่ password KDF แบบใช้หน่วยความจำสูง

การเข้าสู่ระบบคืน session token อายุ 8 ชั่วโมง เก็บไว้ในหน่วยความจำของหน้าเว็บ ตรวจสิทธิ์ที่หลังบ้านก่อนบันทึกหรือเปลี่ยนบัญชี เมื่อเปลี่ยนบัญชี session เดิมทุกเครื่องหมดอายุ เมื่อออกจากระบบ token ของหน้านั้นถูกเพิกถอน มีการจำกัดการลองรหัสผิด 8 ครั้งในช่วง 5 นาที

ผลไพ่บันทึกลง Results เดิม โดยเก็บประวัติ A:F ไว้ และใช้คอลัมน์ G เป็นรหัสรายการพร้อม checksum เพื่อป้องกันบันทึกซ้ำ มี Script Lock ป้องกันการเขียนพร้อมกัน ปุ่ม “บันทึกอีกครั้ง” ใช้รหัสรายการเดิมเมื่อยังไม่ทราบผลการบันทึกแน่ชัด ข้อมูลข้อความที่เสี่ยงกลายเป็นสูตรจะถูกเก็บเป็นข้อความ

ไม่เผยแพร่ค่ารหัสผู้ดูแลเดิมหรือ Script Properties ใน Git ต้องเก็บค่าที่ใช้ย้ายบัญชีไว้ในโปรเจ็กต์ Apps Script ส่วนตัวเท่านั้น และใช้บัญชีเดิมเข้าสู่ระบบครั้งแรก จากนั้นเจ้าของเปลี่ยนรหัสผ่านเองผ่านเมนูบัญชี

หน้าเว็บและรูปไพ่บน GitHub Pages เป็นไฟล์สาธารณะ การเข้าสู่ระบบป้องกันการใช้ API และข้อมูลหลังบ้าน

## พัฒนาและตรวจสอบ

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```sh
npm test
npm run preview:qa
```

เปิด `http://127.0.0.1:4173/` บัญชีจำลอง `qa-owner` / `local-test-only` ใช้ API จำลองในเครื่องและไม่ติดต่อ Google Sheets การเริ่มเซิร์ฟเวอร์จำลองใหม่จะคืนบัญชีจำลองเดิม

`npm start` ใช้ Apps Script จริง การยืนยันเปิดผลจะบันทึกลงชีตจริง

## ไฟล์

- `index.html`, `select_n_show.html` หน้าระบบเดียวกัน
- `app.js` บัญชี ขั้นตอนเลือกไพ่ ผลลัพธ์ และการเรียก API
- `theme.css` ชุดสี ฟอนต์ ปุ่ม และรูปแบบหน้าจอ
- `styles.css` สีหมวดไพ่ตามความหมายเดิมและการเรียกธีม
- `backend/Code.gs` โค้ดหลังบ้านที่ไม่มีข้อมูลลับ
- `tests/` การทดสอบขั้นตอน บัญชี สิทธิ์ และการบันทึกซ้ำ
- `images/`, `images_small/` ภาพไพ่จากต้นฉบับ

เผยแพร่ GitHub Pages จาก `main` ที่ root ต้องอัปเดต Apps Script และทุก active deployment ให้เป็นโค้ดบัญชีเดียวด้วย ไม่เพียงแก้หน้าเว็บ

ภาพไพ่และชื่อแบรนด์ใช้ตามต้นฉบับของเจ้าของระบบ ไม่ได้เพิ่มใบอนุญาตเผยแพร่ต่อ
